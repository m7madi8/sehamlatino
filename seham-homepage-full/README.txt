SEHAM LATINO — Homepage full package (HTML + JS + CSS + images + video)
=======================================================================

هذه الحزمة بديل كامل للحزمة السابقة (CSS+صور فقط).

البنية:
- index.html                 الصفحة الرئيسية (عربي)
- en/index.html              الصفحة الرئيسية (إنجليزي)
- studio.css                 التنسيق الرئيسي
- about-portrait.css         تنسيق بورتريه About
- studio.js                  منطق الحركة/الفيديو/القائمة
- about-portrait.js          منطق البورتريه
- img/                       صور الصفحة
- assets/decorative/         SVG زخرفي حالي (مؤقت)
- assets/silk/               أصول القماش الفوتوغرافية للاستخدام الصحيح
  - silk-fabric-texture.jpg  قماش حريري شفاف التدرجات (مرجعي)
  - serene-reach-burgundy.png صورة سهام مع قماش واقعي
- assets/video/              فيديوهات الهيرو والدورة + poster

ملاحظة تنفيذ مهمة:
لا تعتمد SVG كبديل للقماش. المطلوب WebP بخلفية شفافة بتفاصيل فوتوغرافية
للطيات والشفافية، وربط الأقسام عبر طبقات CSS، وإطار الصورة البيضاوي منفصلاً.
