# صور الموقع

الملفات منظّمة حسب الاستخدام (لم تُعدَّل الصور نفسها، فقط نُقلت للمجلدات):

| المجلد | المحتوى |
|--------|---------|
| `brand/` | الشعارات، الأيقونة، التوقيع |
| `hero/` | صور الهيرو والجوال |
| `course/` | غلاف الدورة |
| `content/` | صور المحتوى والأقسام |
| `footer/` | حرير الفوتر |
| `ui/` | عناصر القائمة والواجهة |
| `_raw/` | ملفات مصدر خام (CR3) — غير مستخدمة في الإنتاج |

المسارات في HTML/CSS: `img/<مجلد>/<اسم الملف>`
